Data & Export

Where is the data? Products and orders live in this browser's localStorage — keys jf_admin_products and jf_orders. Download them any time:

Backend mode: when this store runs on the Node backend, products and orders live in the server database (backend/data/db.json) and the admin login is checked on the server with a hashed password + JWT token — visible from any device. On GitHub Pages there is no backend, so this panel falls back to demo mode: data saves only in this browser, and the demo password is written in admin.js.
